구내식당 입찰알림 사용법
=======================

[무엇을 하나]
 매시간 자동으로 아래 3곳을 확인하고, 새 공고가 있으면 윈도우 알림을 띄웁니다.
 알림을 누르면 "입찰현황.html" 에 모든 공고가 한 화면에 모여 있습니다.
  1) 나라장터  : 공고명에 식당/급식/식음/카페테리아가 들어가고 광주·전남·나주 등 지역 기관인 용역·물품 입찰
  2) 한전 전자조달(srm.kepco.net) : 한국전력공사 + 한전KPS·전력거래소·한전FMS·한전CSC·한국에너지공과대 식당 공고
     (한전KDN은 나라장터에 공고하므로 1)에서 잡힘. '전기넷'은 입찰정보를 모아 보여주는 민간 앱이라 따로 연결하지 않음)
  3) 전남대학교 홈페이지 입찰공고 게시판
  4) 온비드 : 국유·공유재산 식당 "유상 사용자 선정 / 사용수익허가 / 위탁운영" 공고 (임대만, 광주·전남권)
     ※ 전남대 햇들마루·학생마루 식당 운영자 선정은 나라장터가 아니라 온비드(재무과)에 올라옵니다.
  5) 국방전자조달(d2b.go.kr) : 광주·전남 지역 부대 용역 입찰 (병영식당 민간위탁 급식 등)
  6) 홈페이지 입찰 게시판 : 전남대병원, 조선대, 호남대, 광주여대, 동신대, 광주보건대, 광주대
  7) 코레일 전자조달(ebid.korail.com) : 용역·물품 공고 중 광주·전남 식당 공고

[탭 3개]
 광주권 진행중 / 전남권 진행중 / 지난 공고(최근 5개월, 마감 지난 것)
 지난 공고는 참고용이라 알림을 보내지 않습니다. 기간은 config.json 의 "지난공고_보관_일"(기본 150일)로 바꿉니다.
     ※ GIST는 구매시스템이 보안프로그램 설치를 요구해서 직접 연결하지 않고, 나라장터에서 '광주과학기술원'으로 잡습니다.
     ※ 위 대학들은 나라장터에도 공고하므로 나라장터 쪽에서도 함께 잡힙니다.

[나라장터]
 로그인·인증키 없이 나라장터 '입찰공고목록' 화면에서 공고명으로 검색합니다 (최근 1개월).
 Edge 브라우저가 화면 없이 잠깐 떴다 닫힙니다. 한 번 확인에 1~2분 걸립니다.
 ※ 기관명에 지역(광주·전남 등)이 없는 곳(예: ○○복지관)은 걸러질 수 있습니다.
   빠지는 곳이 있으면 config.json 지역_키워드에 그 기관명을 추가하세요.

[공고 요약]
 나라장터 공고는 상세화면에서 핵심항목을 자동으로 읽어 현황 페이지의 "공고 요약"을 누르면 펼쳐집니다.
 (계약방법, 참가가능지역, 업종제한, 사업금액·추정가격, 평가비율, 참가등록·입찰마감·개찰 일시 등)
 새 공고만 상세를 열기 때문에 처음 한 번은 오래 걸리고(공고 1건당 약 20초), 이후엔 빠릅니다.

[휴대폰으로도 받고 싶으면 (선택)]
 텔레그램에서 @BotFather 로 봇을 만들고 토큰과 채팅ID를 config.json 에 넣으면 됩니다.

[GitHub 자동 실행 - PC가 꺼져 있어도 됨]
 저장소 : https://github.com/hanvit5999-code/gwangju-cafeteria-bids
 현황 웹페이지 : https://hanvit5999-code.github.io/gwangju-cafeteria-bids/
 매일 오전 9시에 GitHub 서버가 자동 실행 → 웹페이지 갱신. 결과 기록은 저장소의 data/ 폴더에 저장됨.
 수동 실행 : 저장소 → Actions → "매일 입찰 확인" → Run workflow
 휴대폰 알림 : 저장소 Settings → Secrets → Actions 에 TELEGRAM_TOKEN, TELEGRAM_CHAT_ID 를 넣으면 텔레그램으로 옴
 프로그램을 고친 뒤 올릴 때 : 이 폴더에서  git pull  후  git add -A ; git commit -m "수정" ; git push

[직접 확인]  지금확인.bat 더블클릭 → 바로 확인 후 현황 페이지가 열립니다.
[광주권 / 전남권 탭]
 현황 페이지가 두 탭으로 나뉩니다.
  - 광주권: 광주 + 나주·담양·화순·장성, 그리고 전남대·한전·KDN·에너지공대
  - 전남권: 목포·여수·순천·광양·무안 등 그 밖의 전남 시군
 config.json 의 광주권_지역 / 광주권_기관 / 전남권_지역 / 제외_지역 으로 조정합니다.
[키워드 바꾸기] config.json 의 검색_키워드 수정 (제외 단어는 입찰알림.py 의 EXCLUDE: 식자재·김치류·공산품·축산물·농산물·수산물 등)
[자동실행 끄기] 작업 스케줄러 → "구내식당_입찰알림" 삭제
[기록]  log.txt
